02 / WHAT MANAGED MEANS

Delivery is a milestone.
Operation is the service.

A once-off website project can end at handover.

Managed Web Services means responsibility continues after launch. We remain responsible for the agreed technical operation of your website: keeping it deployed, available, monitored, maintained and improved within the defined service scope.

The exact responsibilities, service levels and change boundaries are confirmed in your selected package, contract and scoped engagement.

Once-off project
Build → Deliver → Handover
Managed service
Build → Deploy → Operate → Monitor → Maintain → Improve
